NEXUS-RISK: AML Detection Engine

An open research project that screens Ethereum addresses against committed threat-intel lists and scores transaction behaviour. This page is the project's public demo: it runs one real check from the engine, in your browser, against the data committed in this repository.

This is the same membership check the engine's list rules perform, run against the committed snapshot in addresses/ on the main branch. Behavioural scoring needs the address's transaction history and is not part of this page. A "not found" result means only that this snapshot does not list the address. It is not a statement that an address is safe.

What is verified, and what is not

Verified, from this repository:

  • The feed pipeline and the committed snapshot in addresses/, guarded by a fail-closed validator. The counts above were computed from the files themselves.
  • The rule catalog: 23 detection functions, documented in docs/RULES.md.
  • The test suite: 166 test functions covering the engine, the feeds, and the API.

Not yet verified:

  • Any detection rate, precision, recall, or false-positive figure. No labelled evaluation against independent ground truth has been completed for this engine.
  • Historical figures once shown for this project were computed on data that is not in this repository and cannot be reproduced from it. They are not claimed here.

This is a research and portfolio project, not a validated production system.
